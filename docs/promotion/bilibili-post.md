标题：我给 DeepSeek Harness 养了一只汉字水墨鲸鱼｜墨池 Inkpond 安装演示

简介：

墨池 Inkpond：给 DeepSeek Harness 会话界面铺一层可交互的汉字水墨背景。
大肥鲸会游动、吃饭、喷米，也会响应指针。另有莲池、山水、清明上河、二十四节气和北冥，共六个场景。

00:00 墨池与大肥鲸
00:03 大肥鲸实录（80% 浓度展示，默认 45%）
00:15 莲池实录（45% 浓度）
00:21 六场景设置
00:26 三步安装指南
00:34 新建空白会话

安装：DSH → 插件 → 添加插件 → 填写 dsh-inkpond@0.3.5 → 选择 npm 官方源 → 安装。
安装后记得新建空白会话；若宿主提示重启，请按提示重启。默认仅新会话显示，已有偏好保留。

源码与完整指南：https://github.com/shin4/inkpond-dsh
npm：https://www.npmjs.com/package/dsh-inkpond

不读取聊天内容，不注册模型工具，不发送遥测。手动检查更新或升级时，由 DSH 宿主访问包源。
实录环境：macOS / DSH 0.2.2-rc.1 Web / 墨池 0.3.5。原生桌面壳及 Windows/Linux 尚未实测。

独立社区插件，与 DeepSeek 官方无隶属关系。代码 MIT；绘制核心来自独立 inkpond，字体采用 SIL OFL。
视频为真实宿主录屏配说明卡片，无配乐、无配音。欢迎反馈安装是否顺利，以及喜欢哪个场景。
